The base WINE applications have been installed to support a future
installation of Windows programs such as VARA HF, VARA FM, and VARA
Terminal. These applications can't be installed by this script. Install
them from a desktop session with the scripts in $HOME/add-ons/wine.

If you previously made a backup copy of your WINE installation using
the "$HOME/add-ons/wine/05-backup-wine-install.sh" script, restore it in
your home folder instead:

   cd ~ && tar -xzf /path/to/etc-wine-backup-*.tar.gz

Confirm that you see a `.wine32` directory in your home folder.
